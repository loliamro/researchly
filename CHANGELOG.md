# Changelog

## v1.0.1 (2026-11-25)
- Shorter, trigger-focused skill description, so Claude picks the skill up on its own more often
  ("is it true…", "give me sources", essays, reports…) and the full text shows on the Skills page.
- Added **quick formats** to `SKILL.md`: the "Is it true…?" fact-check answer and the quick
  research answer, available without loading a reference file.
- Clear rule for answers without web access: keep the format and tag sources
  `Unverified (from memory)`.
- The single-claim format is now defined only in `SKILL.md`; `source-evaluation-and-fact-checking.md`
  points to it.
